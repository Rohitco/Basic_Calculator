Create a calculator that perform arithmetic calculations.
Scientific Calculator (Web App)

Overview

This project is a modern, fully functional scientific calculator built as a single-page web application using pure JavaScript, HTML, and Tailwind CSS. It is designed to emulate the look and feel of a high-end physical scientific calculator, featuring a dark aesthetic, robust mathematical operations, and advanced utility functions.

The application is entirely self-contained within a single calculator.html file, making it easy to deploy, share, or run locally.

🚀 Key Features

This calculator goes beyond basic arithmetic, offering a wide range of functions essential for scientific and engineering calculations:

Core Arithmetic: Addition (+), Subtraction (-), Multiplication (×), and Division (÷).

Advanced Operations:

Exponentiation: Power function (EXP or ^).

Square/Cube: Dedicated buttons for squaring (x²) and cubing (x³).

Percentage: Calculate percentages (%).

Utility & Control:

Clear: Full reset of the display and operation (AC).

Sign Toggle: Change the sign of the current number (+/-).

Backspace: Delete the last digit entered (Back).

Random Number: Insert a random number between 0 and 1 (RND).

State Management:

Memory Functions: Store, add, or subtract from memory (M+, M-, MR).

Last Answer: Recall the result of the previous calculation (Ans).

Error Handling: Custom, non-disruptive message box for critical errors like division by zero.

💻 Tech Stack

HTML5: Structure and content.

Tailwind CSS: Used for all modern, responsive styling and layout, ensuring a professional, dark theme.

JavaScript (ES6): Core calculation logic and state management implemented via a clean Calculator class.

🎨 Design & Aesthetics

The design prioritizes usability and a sleek scientific look:

Dark Theme: Uses dark slate and black backgrounds with high-contrast text and vibrant blue, indigo, and orange accents for functions and operators.

6-Column Grid: A dense, scientific layout to accommodate all functions without clutter.

Responsive Buttons: Buttons feature rounded edges and subtle hover/active states for a satisfying user experience.

🛠️ How to Run Locally

Clone this repository or download the calculator.html file.

Open calculator.html directly in any modern web browser (Chrome, Firefox, Edge, Safari). No server is required!
